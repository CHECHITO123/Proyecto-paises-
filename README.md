# Atlas — Buscador de países

Aplicación web responsive conectada a CountriesNow API. Combina sus endpoints de banderas, capitales, monedas y población para crear fichas de países.

## Tecnologías

- HTML5 semántico
- CSS3 responsive
- JavaScript (Fetch API, DOM y async/await)
- CountriesNow API

Abre `index.html` con Live Server para ejecutar el proyecto.
